    Dépannage

    Ce chapitre rassemble les situations qui peuvent vous surprendre, et ce qu'il faut faire. Il s'enrichit avec le manuel : chaque domaine du réalignement y ajoute les siennes.

    Lancer BIMopen

    L'application web affiche « BIMopen non si è avviato » et une erreur

    Le navigateur n'a pas pu fournir à BIMopen une surface graphique : le message se termine par webgl2 not available ou par une erreur WebGPU. BIMopen dans le navigateur nécessite WebGPU ou WebGL2.

    • Activez l'accélération matérielle dans les paramètres du navigateur, puis rechargez la page.
    • Essayez un autre navigateur, ou une version plus récente du même navigateur.
    • Ajoutez ?webgl à l'adresse pour utiliser WebGL2 même là où WebGPU existe mais ne fonctionne pas.

    L'application de bureau ne se compile pas sous Linux

    L'interface nécessite les fichiers de développement de xkbcommon, Wayland et GTK 3. Sous Debian et Ubuntu :

    sudo apt-get install -y libxkbcommon-dev libwayland-dev libgtk-3-dev

    L'interface

    La palette Propriétés, l'Arborescence du projet ou la ligne de commande a disparu

    Elles se ferment avec le × de leur titre, ou depuis Vue ▸ Fenêtres ▸ Interface utilisateur. Cochez-les à nouveau dans Interface utilisateur. Le bouton Propriétés de l'onglet contextuel affiche aussi à nouveau la palette.

    Ce que je tape aboutit dans la ligne de commande

    Tout ce que vous tapez lorsqu'aucun champ n'est en cours de modification va dans la ligne de commande : c'est ainsi que fonctionnent les raccourcis saisis. Pour taper dans un champ de la palette Propriétés ou d'une boîte de dialogue, cliquez d'abord sur le champ.

    Un bouton est grisé

    Certains outils ne fonctionnent que dans la vue appropriée, et leur info-bulle en indique la raison. Ligne de limite de surface et Surface nécessitent un plan de surfaces ouvert : l'info-bulle indique Ouvrez d'abord un plan de surfaces. Enregistrer la vue nécessite une vue 3D ouverte ; Composition de la feuille ▸ Vue nécessite une feuille ouverte ; Annuler et Rétablir sont grisés lorsqu'il n'y a rien à annuler ou à rétablir.

    DL lance une cote au lieu d'une ligne de détail

    DL est la forme courte de la cote linéaire. Pour dessiner des lignes de détail, utilisez Annoter ▸ Détail ▸ Ligne de détail, ou tapez detailline.

    Modélisation

    « aucun mur à cet endroit »

    Une porte ou une fenêtre doit être placée dans un mur. Cliquez sur le mur lui-même, ou indiquez un point sur sa ligne dans la ligne de commande.

    Une hauteur définie dans la ligne de commande est énorme

    Dans la ligne de commande, un nombre sans unité est en mètres : set Unconnected Height 2700 rend le mur haut de 2700 m. Annulez avec Ctrl+Z et écrivez l'unité : 2700mm ou 2.7m. Dans la palette Propriétés, un nombre sans unité est exprimé dans les unités du projet.

    Fichiers

    Le travail non enregistré a disparu après Nouveau, Ouvrir ou Projet d'exemple

    Ces commandes remplacent le projet en cours sans demander de confirmation. Enregistrez avant de les utiliser : l'astérisque après le nom du projet dans la barre de titre indique qu'il y a des modifications non enregistrées.

    Ouvrir… dans le navigateur n'affiche pas de boîte de dialogue de fichier

    Dans le navigateur, faites glisser le fichier .bimopen dans la page : la ligne de commande indique Glissez un fichier .bimopen dans la fenêtre pour l'ouvrir.

    bimopen-cli affiche son mode d'emploi et s'arrête

    Les arguments ne sont pas ceux qu'il attend : il se termine avec le code 2 et affiche le mode d'emploi. Une commande qui échoue se termine avec le code 1 et un message indiquant quelle ligne a échoué. Voir Ligne de commande et MCP.
