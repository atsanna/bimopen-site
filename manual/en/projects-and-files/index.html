    Projects and files

    This chapter describes how a project is created, opened, saved and exchanged with other programs, its settings and the options of BIMopen itself.

    Creating a project

    application menu ➤ New ➤ Project… opens New project:

    • Template file: BIMopen's default template, or the one set in Options ➤ File Locations; the BIMopen imperial template (see Imperial units); a template file chosen with Browse…; or None, which starts from two levels and one type of each kind and asks for the system of measurement: Imperial or Metric.
    • Create new: Project or Project Template.

    A project made from a template has everything the template had: types, settings, views, sheets, project information and print settings. Saving it asks for a name, so the template is not overwritten.

    Templates

    A template is a .bimtpl file. application menu ➤ Save As ➤ Template… saves the open project as a template; a project created as a Project Template, or a template opened, is saved as a template too.

    Opening a project

    Ctrl+O or application menu ➤ Open… opens a project. application menu ➤ Recent Documents lists the latest projects, the most recent first; a pin keeps a project in the list. Without a file, BIMopen starts on Recent Files, with the recent projects, Open…, New and the Sample project (unless Enable Recent Files page at startup is unticked in the options). Dropping a project file on the window opens it too.

    A project already open in another BIMopen window opens read-only: Save asks for a new name. If BIMopen stopped without saving (a crash, a power cut), opening the project again brings the unsaved work back as unsaved changes.

    Saving

    Ctrl+S, or a click on the save state in the top bar, saves the project; until then the file stays as it was last saved, and the top bar says Unsaved changes. application menu ➤ Save As ➤ Project… writes it to a new file and goes on there.

    Save As ➤ Options… opens File Save Options: Maximum backups keeps that many earlier versions beside the file (house.0001.bimopen, house.0002.bimopen…), deleting the oldest; Compact file rewrites the file without its obsolete parts at the next save.

    When a changed project stays unsaved for the interval set in Options ➤ General (Save reminder interval, 30 minutes to start with), Save Reminder offers to save it, not to save it, or to change the interval.

    One project is open at a time: the project opened takes the place of the one open, and the views of that one close with it. Opening the project already open leaves it as it is, when it has no unsaved changes; with changes, answering No to the question to save them drops them and opens the file again as last saved, as closing it without saving and reopening it.

    Before New, Open…, a recent document, a dropped file, open at the command line, the sample project, or closing the window, a changed project asks Save changes to …?: Yes saves it, No drops the changes, Cancel keeps it open.

    In the browser, Open… uses the browser's file chooser, and Save downloads the file; backups, crash recovery and read-only opening need a file on disk and are desktop-only.

    Project settings

    Project information

    Settings ➤ Settings ➤ Project information sets the project's name, number, client, address, issue date and status: the title blocks of every sheet show them.

    Project units

    Settings ➤ Settings ➤ Project units lists the quantities (length, area, volume, angle, slope and the others) with a sample of each, and the Decimal symbol/digit grouping. Format… of a quantity sets its unit, its Rounding (a number of decimals, or Custom with an Increment factor, such as 5 mm), its Unit symbol, Suppress trailing zeros, the plus sign for positive values and digit grouping.

    Imperial units

    In Format… the units of a length are in two groups, Metric and Imperial: Feet and fractional inches (5' - 6 1/2"), Fractional inches (66 1/2"), Decimal feet and Decimal inches. Areas can be in Square feet, Square inches or Acres, volumes in Cubic feet, Cubic inches or Cubic yards, slopes as Rise/12" or as a ratio. With fractions, Rounding is to the nearest inch or to the nearest 1/2" to 1/256"; a value that rounds up to 12" is carried into the feet: at 1/16", 11 63/64" reads 1' - 0". Suppress 0 feet writes 4" for 0' - 4", Remove spaces writes 1'-2" for 1' - 2", and Unit symbol chooses between ' and ft, or ft² and SF. Other values shows the format on a few more values.

    A schedule field's Field Format… and a dimension type's Units Format have the same fields, besides Use project settings: a takeoff can give volumes in cubic yards in a project in cubic feet, and a dimension type for details can round to 1/32" where the plans round to 1/16".

    The model is kept in metres: changing the units changes how values are shown and typed, never the geometry. Switching a project from metric to imperial and back leaves every element where it was.

    In a project in feet and inches the view scales are the architectural ones, from 12" = 1'-0" to 3/64" = 1'-0", and the engineering ones, from 1" = 10'-0" to 1" = 100'-0": in the view bar, in the Properties and on sheets. A scale that is neither shows as a ratio.

    The BIMopen imperial template has the same set of types as the metric one, in US trade sizes: walls of 2x4 and 2x6 wood studs, of 8" blocks and brick, of metal studs; doors from 30" to 36" x 80"; windows with a 3'-0" sill; stairs with risers of at most 7 3/4" and treads of at least 10"; railings 36" and 42" high. Lengths and dimensions are rounded to 1/32", the length dimension snap increments are 4', 1', 6" and 1", the work plane grid is 4', plans are at 1/8" = 1'-0" and text is 3/32" and 1/8" high. These are starting points: each one can be changed in the project. Changing the units of a project does not rename its types.

    Tip: to keep drawings readable on site, give the dimension types a coarser rounding: in a dimension type's Type Parameters, Units Format opens Format; untick Use project settings and round to 1/16" or 1/8".

    Typing lengths

    A length typed in the Properties, on a temporary dimension, in the options strip, in a dialog or at the command line is read this way:

    • with a unit, in that unit, in any project: 300mm, 1.2 m, 1 m 20 cm, 6", 5.5', 5.5 ft;
    • feet and inches: 5'6", 5' 6 1/2", 5'-6 1/2"; after the feet the last " can be left out (5'6), and inches from 12 up are carried into the feet (5' 14" is 6'-2");
    • a number without a unit is in the project's unit of length; in a project in feet, two numbers are feet and inches: 8 6 is 8'-6", 8 6 1/2 is 8'-6 1/2";
    • fractions are of an inch; a fraction of a foot is written as a decimal (5.5');
    • after =, a formula: =10' + 6", =12'/5, =3000mm/2; its numbers without a unit are in the project's unit.

    The decimal symbol is the project's. While a value is being edited it is shown at full precision (to 1/256" in feet and inches), so confirming it unchanged changes nothing. At the command line a number without a unit is in metres in a metric project and in feet in a project in feet and inches; a length can always carry its unit: wall 0,0 20',0.

    Sun Settings

    Settings ➤ Additional settings ➤ Sun Settings opens the sun settings of the active view, the same as the sun button of the view control bar (see Views and graphics).

    Options

    application menu ➤ Options has four tabs; the choices are kept between sessions.

    Tab What it sets
    General The save reminder interval
    User Interface The theme (Light or Dark), the language, the interface style and size; Enable Recent Files page at startup; in the Classic style, the ribbon tab after a selection ends or a tool closes (Stay on the Modify tab or Return to the previous tab) and Display the contextual tab on selection; Tooltip Assistance (None, Minimal, Normal, Extra High)
    Graphics Invert background color, Selection color, Highlight color, Use anti-aliasing for 3D views, Temporary Dimension Text Appearance (size and background)
    File Locations Default template file path (the template of New) and Default path for user files (where the file dialogs open)

    Copying settings from a project

    Settings ➤ Settings ➤ Copy Settings from Project copies settings from another project into this one. In Select Items To Copy, choose the project with Browse… (Copy from:), then tick what to copy: the types of walls, floors, roofs, doors and windows, stairs, railings, curtain panels and mullions, line styles, filled region types, materials, fill and line patterns, line weights, styles by category, view templates, filters, viewport types, title blocks, the project units, the print settings and the project information (Check all, None).

    What is copied brings along what it uses: a wall type its materials, a material its patterns, a view template its filters. When names are already in the project, Duplicate Types asks whether to Overwrite them or to transfer the New Only. The whole transfer is one step of undo.

    Exchanging files

    Exporting to IFC

    application menu ➤ Export ➤ IFC… writes the model in IFC4: walls with their axis and body, openings, doors, windows, floors, roofs, stairs, railings, curtain walls, furniture and rooms as spaces, on their storeys.

    Export ➤ Options ➤ IFC Options… opens IFC Export Classes: the IFC class of each category; Not Exported leaves a category out, and Default goes back to the standard classes. The classes are kept with the project.

    Opening IFC files

    application menu ➤ Open ➤ IFC… makes a new project from an IFC2x3 or IFC4 file, in metres or millimetres: storeys become levels, walls are rebuilt from their axis (or from the long side of their body), slabs become floors, doors and windows go in the walls their openings cut, and spaces become rooms. The messages count what was not read.

    Open ➤ IFC Options… opens Import IFC Options: what each IFC class becomes (walls, floors, doors, windows, rooms or Not Imported), and Default. The choices are kept between sessions.

    Objects with a shape that are not walls, floors, doors, windows or spaces are kept as imported objects, to convert: see Importing and converting.

    Other exports

    Printing to PDF and exporting images are described in Sheets, schedules and printing; schedules export as delimited text from the same chapter. bimopen-cli convert exports from the command line (see Command line and MCP).
