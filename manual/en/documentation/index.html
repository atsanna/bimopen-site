    Sheets, schedules and printing

    This chapter describes how the project is documented: sheets, schedules and printed drawings.

    Being written

    This chapter is completed with area R7 of BIMopen's realignment, Documentation and files: each feature is compared with the reference behaviour, corrected where needed and checked through the interface, and only then described here. Schedules are checked and described below; sheets and printing follow.

    Schedules

    A schedule is a table of the elements of the model, and a view like the others: it opens in a window of the drawing area, is tiled, cascaded and switched with plans, sections and 3D views, and is listed under Schedules/Quantities in the Project Browser. It follows every change of the model at once, and every change made in it changes the model.

    Creating a schedule

    View ➤ Create ➤ Schedules ➤ Schedule/Quantities opens New Schedule: choose a category, a name (the default follows the category until one is typed) and Schedule building components or Schedule keys. OK opens Schedule Properties; its second OK creates the schedule and opens its view. Material Takeoff in the same menu lists the materials of the layers of walls, floors and roofs.

    Schedule Properties

    The dialog opens again from the Properties palette of the schedule (each tab has its Edit… button) or from the right button on the schedule in the Project Browser. Its tabs:

    Tab What it sets
    Fields The columns, chosen from Available fields: and put in order; the fields of the rooms the elements are in; Add Parameter… for a project or shared parameter; Calculated Value… for a formula (with + - * / ^, sqrt, round, IF, AND, OR, NOT and units) or a percentage
    Filter Up to four criteria, all of which an element must meet
    Sorting/Grouping Up to four sort levels, each with Header, footer and Blank line; the grand totals; Itemize every instance (off: one row per type)
    Formatting Per field: heading, orientation, alignment, hidden field, Format… (units, rounding, symbol), totals and Conditional Format… (a background colour where a value meets a test)
    Appearance Grid lines and outline with their line styles, the title and the column headers, a blank row, Header text and Body text (size, Bold, Italic); shown when the schedule is on a sheet

    Working in a schedule view

    • A cell edits the element, or its type for a type parameter; every edit is one step of undo.
    • A row selects its elements in every view. Highlight in model on the Modify | Schedule/Quantities tab opens Show Elements in View, which brings a plan forward framed on them; Show goes on to the next view.
    • Rows ➤ Delete deletes the elements of the selected rows, after asking.
    • Headings picked together are joined under a common heading with Group, and parted with Ungroup; Hide column and Unhide all columns work on the column picked.

    Schedules on sheets

    Drag a schedule from the Project Browser onto a sheet. Selected on the sheet, it shows its controls: the Z on the right edge of a segment splits it in two, the arrow in the middle of a segment moves it (dropped on the segment beside it, the two join), the dot at the bottom of a segment moves its last row, and the triangles at the top of the columns set their widths. A double click, or Edit Schedule on the right button, opens the schedule view. The same schedule can go on several sheets.

    Key schedules and material takeoffs

    A key schedule (Schedule keys in New Schedule) defines named sets of values, one row per key, added and deleted with Rows. Its Key Name becomes a parameter of the category: choosing a key for an element gives it all the values of that row.

    A material takeoff lists, for each element, the materials of its layers with their area and volume; its fields can be sorted, grouped and totalled like any other.

    Project and shared parameters

    Manage ➤ Settings ➤ Project Parameters adds parameters to the elements of some categories, or to their types, with a name, a type of value and the group they show in the Properties palette.

    Manage ➤ Settings ➤ Shared Parameters opens Edit Shared Parameters: the shared parameter file in use (Browse…, Create…), its groups and the parameters of each group. A shared parameter keeps its name and type, and has an identifier of its own, so that several projects add the same parameter. In Parameter Properties, choose Shared parameter and Select… to add one to the project; Export… writes a shared parameter of the project back to the file.

    Exporting and reusing schedules

    • Application menu ➤ Export ➤ Reports ➤ Schedule… writes the schedule as delimited text: Export Schedule sets the field delimiter, the text qualifier and which headings and group rows go in the file.
    • Create view template from view… on the right button of a schedule makes a view template with its fields, filter, sorting, formatting and appearance; Apply view template… gives them to another schedule.
    • Save to New File… on the right button writes the schedule's setup, without the elements, to a file of its own. Insert ➤ Import ➤ Insert from File ➤ Insert Views from File… brings the schedules of another project into this one, with their project parameters.
