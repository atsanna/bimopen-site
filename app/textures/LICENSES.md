# BIMopen texture library — sources and licences

Every texture in this folder is in the public domain under the **Creative Commons CC0 1.0
Universal** dedication (<https://creativecommons.org/publicdomain/zero/1.0/>). No attribution is
required; we give it anyway. Each set was downloaded from its official page on **ambientCG**
(<https://ambientcg.com>, licence: <https://docs.ambientcg.com/license/>), whose asset page states
the CC0 licence, as the 1K JPG package, and repacked for BIMopen:

- `<id>_albedo.jpg`: the colour map, 1024 px on the long side, sRGB;
- `<id>_normal.jpg`: the normal map (OpenGL convention, +Y up), same size, linear;
- `<id>_orm.jpg`: occlusion (R), roughness (G) and metalness (B) packed, half size, linear; a
  map the set did not have is constant (occlusion 1, metalness 0).

Glass and water have no images: the program makes them (water's normal map is procedural).
Nothing here comes from any other program's library. To add a texture: CC0 only, from the
original source, with a row below.
