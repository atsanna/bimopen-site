This repository holds the **built** website of BIMopen, served by GitHub Pages, and the
**test builds** of the program in its [Releases](https://github.com/atsanna/bimopen-site/releases).
It contains no source code: only the pages, their translations and images, as they are published.

**BIMopen** is a BIM modeller written in pure Rust: you model the building (levels, layered
walls, doors and windows, curtain walls, floors, roofs, stairs, rooms) and plans, sections,
elevations, 3D views, schedules and sheets are views of the same model, kept in step. It opens
IFC files (IFC2x3 and IFC4) as new projects, exports IFC4 and prints vector PDFs. It runs in the
browser, on Windows, Linux and Android, with two interface styles in six languages: Italian,
English, German, French, Spanish and Arabic (right to left).

Developed with [Claude Code](https://claude.com/claude-code).

## Download

Test builds for **Windows** (10/11, 64 bit), **Linux** (x86_64) and the **web** version are
published as prereleases under [Releases](https://github.com/atsanna/bimopen-site/releases),
with a `SHA256SUMS.txt` file to check them. The [download page](https://bimopen.it/download.html)
of the website lists the latest one and what changed.
