    Keyboard shortcuts

    BIMopen has two kinds of shortcuts: keys, such as Ctrl+Z, which act at once, and typed shortcuts, such as WA, which you type letter by letter and confirm with Enter, like any command. Typed shortcuts are the same in every language.

    On macOS, Cmd takes the place of Ctrl.

    Keys

    Key What it does
    Ctrl+Z Undoes the last change
    Ctrl+Y or Ctrl+Shift+Z Redoes the change just undone
    Ctrl+S Saves the project; a project never saved asks for a file name
    Ctrl+P Opens Print
    Ctrl+A Selects the elements of the open plan's level, or of the whole model in a 3D view
    Del Deletes the selected elements, and the elements they host
    Home Fits the whole view in its window
    F1 Opens the page of this manual about the open dialog, the ribbon button under the mouse or the active tool
    Esc Cancels the step in progress; pressed again, ends the tool; with no tool, clears the selection
    Enter Runs the line typed at the command line; confirms a value in the Properties palette
    Up / Down At the command line, the lines typed before
    Space While drawing walls, swaps the exterior and interior side; while placing a component or a detail component, rotates it
    Shift While drawing, keeps segments horizontal or vertical (or frees them, when Ortho is on); with a click or a window, takes elements out of the selection; while dragging, frees a joined wall or keeps the move horizontal or vertical
    Ctrl + click Adds an element to the selection; held when a drag starts, places a copy
    Tab / Shift+Tab Highlights the next (previous) element under the cursor, or a chain of joined walls and lines
    Ctrl+Left Selects again what was selected before
    Left Right Up Down Move the selection a small step; with Shift, ten steps

    Ctrl+Z, Ctrl+Y, Ctrl+A, Del and Home act on the model only while you are not typing in a field: in a field they act on the text.

    In a floor, roof, stair or railing sketch, Esc (or a double-click) also finishes the sketch when it has enough points.

    In the Text Note dialog, Ctrl+Enter inserts the note and Esc cancels it.

    Mouse

    In plans and sections In 3D views
    Wheel Zoom at the cursor Zoom
    Middle button, drag Pan Pan; with Shift, orbit
    Left button, drag Selection window (left to right: inside; right to left: touching), or moves the selected elements The same
    Right button Context menu; with a tool active, cancels the step The same; dragging, orbit
    Double-click Finishes a sketch –

    Typed shortcuts

    Type the letters while no field is being edited, then press Enter. Without arguments, a shortcut starts the tool or opens the dialog; with arguments, it runs the command at once (see Command line and MCP).

    Annotating and detailing

    Shortcut Command Starts
    DI dim Aligned dimension
    DL lineardim Linear dimension
    DA angulardim Angular dimension
    TX text Text
    TG tag Tags the untagged doors and windows of the level
    – detailline Detail line
    RG region Filled region
    – mask Masking region
    CD detailcomponent Detail component
    RD repeatingdetail Repeating detail
    IS insulation Insulation

    Note

    The tip of the Detail line button shows DL, but DL starts the linear dimension, as the tip of Linear says. To start the detail line by typing, use detailline.

    Views and settings

    Shortcut Command Starts or opens
    SE section Section
    EL elevation Elevation
    DT callout Callout (the Detail button)
    DS splitsegment Split Segment of a section
    VD draftingview The Drafting view dialog
    PP floorplan The Floor Plan dialog
    DV duplicateview Duplicates the active view
    VG or VV vg Visibility/Graphics
    SO objectstyle Object styles
    MA material Materials
    UN units Project units
    PU purge Purge unused
    – filter Filters
    – viewtemplate View templates
    – applytemplate Apply a view template to the active view
    – linestyle Line styles
    – fillpattern Fill patterns
    – saveview3d Saves the {3D} view with a name
    – renameview Renames the active view

    The commands with – have no short form, but their whole name works the same way. help lists every command and its short forms.
