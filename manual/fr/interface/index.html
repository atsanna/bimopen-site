    L'interface

    La fenêtre de BIMopen comporte les mêmes parties dans la version de bureau et dans la version web. De haut en bas :

    1. la barre de titre, avec le menu de l'application, la barre d'outils d'accès rapide, le nom du projet et de la vue active, le menu des langues et le menu d'aide ;
    2. le ruban, avec ses onglets et ses groupes d'outils ;
    3. la barre des options, avec les réglages de l'outil actif ;
    4. à gauche, la palette Propriétés au-dessus de l'Index du projet ;
    5. la zone de dessin, où les vues s'ouvrent dans des fenêtres, chacune avec sa barre de contrôle d'affichage ;
    6. la ligne de commande, avec le journal de ce qui a été fait ;
    7. la barre d'état.

    Les palettes gardent leur largeur quoi qu'elles affichent : un nom long est raccourci par « … » et son info-bulle le montre en entier. Faites glisser le bord des palettes pour les élargir ou les rétrécir, et la ligne entre Propriétés et l'Index du projet pour partager la hauteur ; BIMopen retient les deux pour la session suivante. Dans le style BIMopen, le panneau d'outils et le panneau d'élément fonctionnent de la même façon.

    En arabe, toute la fenêtre est inversée en miroir : les palettes sont à droite, le ruban et la barre des options se lisent de droite à gauche, et la barre de navigation se trouve sur le bord gauche des vues.

    Menu de l'application

    Le bouton bleu B à l'extrémité gauche de la barre de titre ouvre le menu de l'application : les commandes qui agissent sur l'ensemble du projet.

    Élément Action
    Nouveau Ferme le projet en cours et en démarre un nouveau à partir du gabarit par défaut : deux niveaux avec leurs plans, et les types par défaut
    Ouvrir… Ouvre un projet .bimopen, ou importe un modèle .rvt, choisi dans une boîte de dialogue de fichier. Dans le navigateur, faites plutôt glisser le fichier dans la page
    Projet d'exemple Ouvre la maison d'exemple
    Enregistrer Ctrl+S Enregistre le projet dans son fichier ; un projet jamais enregistré demande un nom, comme Enregistrer sous…
    Enregistrer sous… Enregistre le projet dans un nouveau fichier .bimopen et continue à travailler sur ce fichier
    Imprimer… Ctrl+P Imprime des feuilles en PDF
    Exporter ▸ Exporter IFC4… Écrit le modèle sous forme de fichier IFC4
    Exporter ▸ Exporter le plan SVG… Écrit le plan actif sous forme de dessin SVG
    Exporter ▸ Exporter la vue PNG… Écrit la vue active sous forme d'image PNG
    Documents ouverts Répertorie les fenêtres de vue ouvertes ; cliquez sur l'une d'elles pour l'amener au premier plan
    Options Ouvre la boîte de dialogue Options
    Quitter Ferme BIMopen (version de bureau uniquement)

    Nouveau, Ouvrir… et Projet d'exemple remplacent le projet en cours sans demander de confirmation : enregistrez-le d'abord si vous souhaitez le conserver.

    Warning

    Les modifications non enregistrées sont perdues lorsque vous choisissez Nouveau, Ouvrir… ou Projet d'exemple. L'astérisque après le nom du projet dans la barre de titre vous indique qu'il y a des modifications non enregistrées.

    Options

    Menu de l'application ▸ Options comporte, entre autres, ces réglages :

    Réglage Valeurs Effet
    Interface utilisateur ▸ Langue Italiano, English, Deutsch, Français, Español, العربية La langue de toute l'interface, immédiatement
    Interface utilisateur ▸ Thème Clair, Sombre Les couleurs de la fenêtre. Sombre active aussi Inverser la couleur d'arrière-plan
    Graphisme ▸ Inverser la couleur d'arrière-plan activé, désactivé Des vues avec un arrière-plan sombre et des lignes claires
    Cube d'orientation ▸ Taille du cube d'orientation, Opacité inactive Petit, Moyen, Grand ; de 0 % à 100 % La taille du cube, et combien il se voit pendant que le pointeur est ailleurs
    Cube d'orientation ▸ Garder la scène verticale activé, désactivé En faisant glisser le cube, le modèle ne se retourne jamais ; désactivé, la vue peut passer par-dessus le sommet

    BIMopen mémorise la langue et le thème pour le prochain démarrage.

    Barre d'outils d'accès rapide

    À côté du menu de l'application, la barre d'outils d'accès rapide garde les commandes les plus utilisées à portée d'un clic. Placez la souris sur un bouton pour lire ce qu'il fait et son raccourci.

    Bouton Action
    Ouvrir… (dossier) Comme dans le menu de l'application
    Enregistrer (disquette) Enregistre, Ctrl+S
    Annuler (flèche vers la gauche) Annule la dernière modification, Ctrl+Z. Grisé lorsqu'il n'y a rien à annuler
    Rétablir (flèche vers la droite) Rétablit la modification qui vient d'être annulée, Ctrl+Y. Grisé lorsqu'il n'y a rien à rétablir
    Cote alignée Lance l'outil de cote alignée, DI
    Etiqueter par catégorie Lance Etiqueter par catégorie, comme dans Annotations ▸ Étiquette : cliquez sur un élément pour l'étiqueter, TG
    Texte Lance l'outil de texte, TX
    Vue 3D (cube) Ouvre la vue 3D par défaut, {3D}
    Coupe Lance l'outil de coupe, SE
    Fermer masquées Ferme toutes les fenêtres de vue sauf la fenêtre active. Grisé lorsqu'une seule est ouverte
    Changer de vue Répertorie les fenêtres de vue ouvertes ; la fenêtre active est cochée

    Au milieu de la barre de titre, lorsque la fenêtre est assez large, BIMopen affiche le nom du projet et de la vue active, par exemple Maison d'exemple — BIMopen - Plan : Rez-de-chaussée. Un astérisque après le nom du projet signifie qu'il comporte des modifications non enregistrées.

    À l'extrémité droite :

    • le menu des langues, un globe avec le nom de la langue courante : choisissez-en une autre et l'interface change aussitôt ;
    • le menu ? : Commandes répertorie toutes les commandes dans la ligne de commande (comme en tapant help), et Informations affiche la version, la licence et les crédits.

    ? ▸ Aide (F1) ouvre ce manuel, dans la langue de l'interface, dans le navigateur. F1 ouvre la page de ce que vous faites : la boîte de dialogue ouverte, le bouton du ruban sous la souris (son info-bulle se termine par Appuyez sur F1 pour plus d'informations) ou l'outil actif.

    Clic droit sur un outil du ruban et Ajouter à la barre d'outils d'accès rapide : l'outil entre dans la barre et se lance de là, quel que soit l'onglet ouvert. Clic droit sur n'importe quel outil de la barre, ceux par défaut compris, pour Supprimer de la barre d'outils d'accès rapide ou Ajouter un séparateur (une ligne à sa droite). La petite flèche au bout de la barre, Personnaliser la barre d'outils d'accès rapide, liste les outils par défaut : cochez-en un pour le remontrer, décochez-le pour le retirer. Dans le même menu, Personnaliser la barre d'outils d'accès rapide… ouvre une fenêtre avec les outils de la barre dans l'ordre : Monter et Descendre déplacent celui sélectionné à gauche ou à droite, Ajouter un séparateur met une ligne après lui, Supprimer l'enlève (ou enlève une ligne), OK applique. Afficher sous le ruban déplace toute la barre sous le ruban (ou de nouveau au-dessus). La barre est conservée pour les sessions suivantes. Dans les onglets du ruban et la barre d'outils d'accès rapide, chaque commande a sa propre icône.

    Ruban

    Le ruban regroupe les commandes en onglets, et chaque onglet en groupes : grands boutons, colonnes de trois lignes et grilles d'icônes, comme dans le dessin approuvé de l'interface. Le nom d'un groupe est écrit sous ses boutons. Un bouton avec une petite marque ▾ a un menu : un clic sur le bouton lance la commande, un clic sur la marque ouvre le menu de ses variantes. Poser la souris sur un bouton montre ce qu'il fait et, entre parenthèses, le raccourci à taper pour le lancer. Les commandes que BIMopen n'exécute pas encore sont grisées, et leur info-bulle dit « Pas encore disponible » ; Niveau, Quadrillage et Plan guide sont grisés dans une vue 3D (« Non disponible dans la vue 3D »). Le style BIMopen a les mêmes commandes, avec la même disponibilité.

    L'onglet contextuel

    Lorsque vous lancez un outil ou sélectionnez quelque chose, le ruban passe de lui-même au dernier onglet, qui prend le nom de ce que vous faites : Dessiner : mur pendant le dessin de murs, Sélection : murs lorsque des murs sont sélectionnés, Édition | Sélection multiple avec des éléments de catégories différentes. L'onglet est signalé par une couleur qui lui est propre. Lorsque l'outil se termine, ou que la sélection est effacée, le ruban revient à l'onglet que vous utilisiez.

    Groupe Boutons

    Barre des options

    Sous le ruban, la barre des options commence par le nom de l'onglet contextuel, puis affiche les réglages de l'outil actif. Ils s'appliquent aux prochains éléments que vous placez. À son extrémité, lorsqu'un outil est actif, elle affiche le niveau sur lequel vous travaillez : Niveau : Rez-de-chaussée.

    Outil Réglages de la barre des options
    Mur Hauteur ou Profondeur ; le niveau qu'atteint le mur, ou Non lié avec sa valeur ; Alignement ; Continuer ; Décaler ; Rayon (grisé : les murs courbes ne sont pas encore disponibles) ; Extérieur à gauche ou Extérieur à droite (la barre d'espace les permute)
    Toit La forme : Deux pans, Croupe ou Plat ; Pente, de 5° à 60° ; Débord, jusqu'à 2 m
    Escaliers Largeur, en millimètres ; Type de garde-corps, ou Aucun
    Cotes Ce que le curseur saisit en premier sur un mur : Axes du mur ou Faces du mur
    Détail (repère) L'échelle de la nouvelle vue de détail, ou Référence à une autre vue et la vue de détail ou la vue 2D libre que pointe le repère (toujours activée dans une vue 2D libre)
    Contour de surface Ligne ou Choisir des lignes ; avec Choisir des lignes, Appliquer les règles de surface ou un Décalage
    Outils qui dessinent des lignes Ortho (Maj) : segments horizontaux et verticaux uniquement ; Accrochage : accrochage aux extrémités, aux milieux et aux intersections

    Lorsque Ortho (Maj) est désactivé, maintenir Shift pendant le dessin donne la même contrainte ; lorsqu'il est activé, Shift la libère.

    Cliquez avec le bouton droit sur la barre des options et choisissez Ancrer en bas pour la placer juste au-dessus de la barre d'état ; Ancrer en haut la remet en place. Le choix est conservé pour les sessions suivantes.

    Propriétés

    La palette Propriétés affiche et modifie les paramètres de ce sur quoi vous travaillez. De haut en bas, elle comporte :

    • le sélecteur de type : la famille en petits caractères et le type en dessous. Cliquez dessus pour choisir un autre type : les éléments sélectionnés changent de type ou, lorsqu'un outil est actif, le prochain élément reçoit ce type ;
    • une ligne indiquant ce que la palette affiche, par exemple Murs (1) ou Nouveau : Mur, et le bouton Paramètres du type, qui ouvre les paramètres du type ;
    • les paramètres, par groupes (Contraintes, Graphisme, Identification…). Cliquez sur le nom d'un groupe pour le replier. Les valeurs en gris sont en lecture seule : elles sont calculées à partir du modèle ;
    • le bouton Appliquer, qui valide une valeur en cours de saisie. Enter fait de même.

    Ce qu'affiche la palette dépend de la situation :

    Situation La palette affiche
    Rien de sélectionné, aucun outil Les propriétés de la vue active (échelle, détail, style graphique…), ou de la vue cliquée dans l'Index du projet
    Un outil actif Le type du prochain élément, comme Nouveau : Mur, Nouveau : Porte…
    Un élément sélectionné Son type et ses paramètres d'occurrence
    Plusieurs éléments d'une même catégorie Leur nombre, comme Murs (3)
    Des éléments de catégories différentes Sélection multiple, Communs (5), et le nombre d'éléments de chaque catégorie, comme 3 × Murs

    Les longueurs sont écrites et lues dans les unités du projet (millimètres dans un nouveau projet). Vous pouvez taper une valeur avec son unité, par exemple 2.7m.

    Pour fermer la palette, cliquez sur × dans son titre ; pour l'afficher à nouveau, utilisez Vues ▸ Fenêtres ▸ Panneaux ▸ Propriétés ou le bouton Propriétés de l'onglet contextuel.

    Index du projet

    L'Index du projet répertorie les vues, nomenclatures, feuilles et familles du projet sous forme d'arbre. Son titre porte le nom du projet. Cliquez sur ⊟ ou ⊞ pour replier ou déplier une branche.

    Branche Contenu
    Vues (toutes) ▸ Plans d'étage Les plans d'étage de chaque niveau, à partir du plus bas, et les repères dessinés dans les plans
    Vues (toutes) ▸ Plans de surfaces (…) Les plans de surfaces, une branche par schéma de surfaces
    Vues (toutes) ▸ Coupes, Élévations Les coupes et les élévations
    Vues (toutes) ▸ Vues de détail Les repères dessinés dans les coupes
    Vues (toutes) ▸ Vues 3D {3D}, la vue 3D par défaut, et les vues 3D enregistrées
    Vues (toutes) ▸ Vues 2D libres Les vues 2D libres
    Nomenclatures/Quantités Les nomenclatures du projet, puis les nomenclatures prédéfinies
    Feuilles (toutes) Les feuilles, sous la forme numéro - nom
    Familles Les types du projet, par catégorie : murs, portes, fenêtres, sols, toits, composants et les autres

    Les branches des plans de surfaces, coupes, élévations, vues de détail et vues 2D libres n'apparaissent que lorsqu'elles contiennent quelque chose. La vue active est écrite en gras.

    Avec une vue :

    • un clic affiche ses propriétés dans la palette Propriétés, sans l'ouvrir ;
    • un double-clic l'ouvre ;
    • un clic droit ouvre son menu : Ouvrir, Fermer (ferme ses fenêtres), Dupliquer la vue ▸ (Dupliquer, Dupliquer avec détails), Appliquer un gabarit de vue…, Créer un gabarit à partir de la vue…, Supprimer, Renommer…, Propriétés.

    Le menu d'une feuille comporte Appliquer un gabarit de vue à toutes les vues… à la place des deux éléments de gabarit, et pas de Dupliquer la vue. {3D} ne peut être ni supprimée ni renommée.

    Avec une nomenclature du projet, un clic la sélectionne, un double-clic l'ouvre, et le menu du clic droit comporte Ouvrir, Propriétés de la nomenclature… et Supprimer. Une nomenclature prédéfinie s'ouvre d'un clic.

    Avec un type, sous Familles, un double-clic ouvre ses paramètres du type ; le menu du clic droit comporte Paramètres du type, Dupliquer…, Créer une instance (lance l'outil qui le place, avec ce type) et Supprimer.

    Après un clic dans l'Index du projet, le clavier s'y déplace : Up et Down passent d'une ligne à l'autre (les propriétés de la vue s'affichent dans la palette), Right ouvre une branche, Left la ferme ou remonte à la branche qui contient la ligne, Enter ouvre la vue.

    Les vues vont aussi sur les feuilles d'ici. Faites glisser un plan, une coupe, une élévation, une vue 2D libre, une légende, une vue 3D enregistrée ou une nomenclature sur la feuille ouverte : sa fenêtre suit le curseur et reste là où vous la lâchez. Ou lâchez-la sur le nom d'une feuille dans l'arbre : la feuille s'ouvre et la fenêtre suit le curseur jusqu'à votre clic. Pendant le glissement, l'arbre défile quand le curseur approche de son bord. Le menu contextuel d'une feuille propose Ajouter une vue…. Les vues d'une feuille sont listées dessous ; le menu contextuel d'une vue offre Supprimer de la feuille, et celui de Feuilles (toutes) Nouvelle feuille…. Dans une vue 3D, le menu contextuel offre aussi Zoom sur les étendues 3D : tout le modèle, même les éléments masqués dans la vue. Une vue déjà placée sur une feuille est refusée, avec la raison dans la ligne de commande ; légendes et nomenclatures peuvent aller sur plusieurs feuilles. Une vue 3D enregistrée apparaît sur la feuille avec les arêtes vues depuis sa caméra.

    Le menu contextuel d'un plan, d'une coupe ou d'une vue 2D libre propose Rechercher les vues de référence : les vues qui montrent son symbole et les feuilles où elle se trouve ; Atteindre la vue ouvre celle choisie.

    Barre des vues et des familles

    La barre sous la zone de dessin a trois modes, choisis avec les boutons à gauche :

    • Mode vues : les vrais aperçus des vues, répartis en Toutes, Ouvertes (n), Plans, Coupes, Élévations, 3D, Légendes, Nomenclatures et Feuilles. La vue courante est encadrée, les vues ouvertes ont une ligne colorée. Un clic sur un aperçu ouvre la vue ; le bouton droit ouvre son menu ; glissé sur une feuille, il y est placé.
    • Mode familles : un aperçu pour chaque type, réparti par catégorie. Un clic place ce type ; glissé dans un plan, il est inséré là où on le lâche. Une porte ou une fenêtre lâchée près d'un mur entre dans le mur, le long de celui-ci.
    • Mode commandes : l'historique de la ligne de commande. Un clic sur une ligne saisie l'exécute à nouveau.

    À droite, Afficher filtre les aperçus par discipline et par phase, la zone de recherche par nom, et trois boutons choisissent la hauteur : Aperçus, Compacte et Masquer.

    Panneaux ancrables

    Propriétés et Index du projet sont des panneaux. On fait glisser un panneau par son en-tête : il s'ancre à gauche ou à droite de la zone de dessin, plusieurs en colonne, ou flotte là où on le lâche. Les boutons de l'en-tête l'ancrent à gauche, à droite, le rendent flottant ou le ferment ; Vues ▸ Fenêtres ▸ Panneaux le rouvre. Chaque panneau reste où on l'a mis lors des sessions suivantes.

    Pendant que vous faites glisser un panneau, seuls les endroits où il s'ancre vraiment sont dessinés, chacun comme le panneau qu'il deviendra : la colonne entière d'un côté libre, à sa largeur, ou la partie haute ou basse d'une colonne où un autre panneau est ancré (il va au-dessus ou au-dessous). L'endroit sous le pointeur est dessiné nettement, les autres à peine. Ailleurs rien n'est dessiné, et le panneau reste flottant là où vous le lâchez.

    Le sélecteur de type, en haut de Propriétés, montre un aperçu du type : murs, sols et toits avec leurs couches, portes, fenêtres et objets en petite image. Ouvert, il cherche les types par nom ; ils sont groupés par famille, chacun avec son aperçu. Les flèches déplacent, Enter choisit, Esc ferme la liste.

    Zone de dessin et fenêtres de vue

    Chaque vue que vous ouvrez est une fenêtre dans la zone de dessin. Une vue ouverte à nouveau passe au premier plan ; au moins une fenêtre reste toujours ouverte. Vues ▸ Fenêtres les dispose :

    Bouton Action
    Changer de vue Répertorie les fenêtres ouvertes ; la fenêtre active est cochée
    Répliquer Ouvre une deuxième fenêtre sur la vue active, avec son propre zoom
    Cascade Des fenêtres superposées, chacune avec sa barre de titre : faites glisser un titre pour déplacer une fenêtre, ses bords pour la redimensionner
    Mosaïque Toutes les fenêtres côte à côte, chacune avec une barre de titre ; la fenêtre active a un titre et un cadre bleus
    Agrandir La fenêtre active remplit la zone de dessin ; les autres attendent en dessous
    Fermer masquées Ferme toutes les fenêtres sauf la fenêtre active
    Panneaux Affiche ou masque l'Index du projet, les Propriétés, la Ligne de commande, la Barre d'état et la Barre de navigation

    Cliquez dans une fenêtre pour la rendre active : les outils travaillent dans la fenêtre active, les autres se contentent d'afficher le modèle. En Mosaïque et en Cascade, le × dans la barre de titre d'une fenêtre la ferme.

    Mosaïque place la fenêtre active en haut à gauche et les autres ensuite, de la plus récemment active ; Changer de vue les liste dans le même ordre. Si vous disposez à nouveau après avoir travaillé dans une autre fenêtre, celle-ci passe en premier.

    Interface utilisateur ▸ Raccourcis clavier liste les commandes avec leurs raccourcis. Cherchez une commande par son nom, ou utilisez Filtrer (Tout, Tous les éléments définis, Tous les éléments non définis, Tous les éléments réservés) ; sélectionnez une commande, tapez les touches dans Appuyez sur les nouvelles touches et cliquez sur Affecter. Les mêmes touches peuvent aller à plusieurs commandes : tapées dans la zone de dessin, la barre d'état montre la première, les flèches passent aux autres et Enter ou Space exécute celle affichée ; Exporter… écrit tous les raccourcis dans un fichier XML et Importer… relit un tel fichier comme vos raccourcis (un fichier qui ne nomme aucune commande de BIMopen est refusé, et vos raccourcis restent) ; Supprimer enlève les touches que vous avez ajoutées. Vos raccourcis sont conservés pour les sessions suivantes et lancent la commande quand vous les tapez, comme ceux prévus.

    Un outil ne change jamais la vue active de lui-même. Lancé dans une vue où il ne peut pas travailler (un toit ou une pièce dans une vue 3D, un niveau dans un plan, une surface hors d'un plan de surfaces), il ouvre Atteindre la vue : les vues adaptées, le plan du niveau actif choisi d'avance. Ouvrir la vue ouvre la vue choisie et y lance l'outil ; Annuler laisse tout tel quel. Modifier le contour d'un sol, d'un toit, d'un escalier ou d'un garde-corps, depuis une coupe ou une élévation, demande de même un plan de son niveau, et une nouvelle coupe ou élévation laisse actif le plan où elle a été dessinée. Déplacer, Copier, un Répéter en série linéaire et Symétrie par ligne fonctionnent aussi dans les coupes et les élévations : le long de la vue ; l'axe est le plan vertical perpendiculaire à la vue passant par son premier point, quelle que soit la façon dont il est dessiné. Un Répéter en série radial fonctionne dans les plans et les vues 3D : dans une coupe ou une élévation il reste choisi, mais ses clics ne font rien et la barre d'état demande Linéaire.

    Vues dans des fenêtres séparées

    Une vue peut sortir de la zone de dessin : Fenêtre séparée dans son menu (clic droit dans l'Index du projet, sur sa vignette dans la barre des vues ou sur la barre de titre d'une fenêtre en mosaïque), ou faites glisser la barre de titre d'une fenêtre en mosaïque ou en cascade hors de la zone de dessin. Sur l'ordinateur, la vue s'ouvre dans sa propre fenêtre du système, que vous pouvez aussi déplacer sur un autre écran, redimensionner et agrandir ; sur le web elle flotte dans la page, car le navigateur n'ouvre pas d'autres fenêtres. Une vue flottant dans le programme a aussi Fenêtre du système, pour la mettre dans une fenêtre du système.

    Vous pouvez séparer plusieurs vues à la fois. Chacune garde ses outils, sa barre de contrôle et, en 3D, son cube d'orientation ; la sélection se voit dans toutes, et la vue active est la dernière où vous avez cliqué. Ramener dans la fenêtre principale, en haut de la vue, la ramène dans la zone de dessin ; une vue flottante y revient aussi en la faisant glisser sur la bande en haut de la zone de dessin, qui s'éclaire. Fermer la fenêtre du système la ramène de même. L'endroit de chaque vue séparée reste avec le projet, et à sa réouverture les vues séparées reviennent à leur place.

    Dessiner dans toutes les vues

    Un mur se dessine de la même façon en plan et dans une vue 3D, sur le plan du niveau : dès le premier clic, le mur en cours suit le curseur, en plan comme son empreinte et en 3D comme son volume transparent, à sa hauteur et à son épaisseur ; une ligne pointillée prolonge son axe, et d'autres le tiennent aligné sur les points déjà cliqués de la chaîne. La cote temporaire, bleue avec ses lignes d'attache et ses traits, donne la longueur et l'angle ; tapez une longueur et appuyez sur Enter pour dessiner le mur de cette longueur. Les accrochages (extrémités, milieux, intersections, perpendiculaire, faces et axes des autres murs) marchent aussi en 3D. Le mur sélectionné dans une vue 3D montre, comme en plan, ses cotes temporaires, les flèches d'inversion et les extrémités à faire glisser. Dans les coupes et élévations, un mur ne se dessine pas : Atteindre la vue propose un plan ou la vue 3D.

    Les toits et les sols se dessinent aussi dans la vue 3D, sur le plan de leur niveau : Choisir des murs prend le mur sous le curseur (son sommet s'éclaire en orange, Tab prend toute la chaîne), les lignes se dessinent avec tous les outils d'esquisse et avec les cotes temporaires, et Modifier l'empreinte d'un toit ou d'un sol ouvre son esquisse en 3D. Modifier le contour d'un mur marche en 3D sur le plan du mur, et dans une coupe ou une élévation qui le voit de face.

    Pendant que vous dessinez ou modifiez une esquisse, vous pouvez changer de vue (vignettes, Index du projet, fenêtres séparées) : l'outil reste actif et continue dans la nouvelle vue s'il peut y travailler. Une chaîne de murs commencée en plan continue en 3D depuis son dernier point, et une esquisse de profil commencée dans une élévation continue en 3D. Le mur en cours et l'esquisse se voient dans toutes les vues ouvertes à la fois.

    Barre de contrôle d'affichage

    En bas de chaque plan, coupe, élévation, repère et vue 2D libre :

    Contrôle Action
    L'échelle, par exemple 1 : 100 Ouvre la liste des échelles ; sous Personnalisée, tapez-en une autre, comme 1 : 75, puis appuyez sur Enter
    Détail Faible, Moyen ou Élevé
    Cadrer la vue Cadre la vue sur sa zone cadrée, ou cesse de la cadrer ; un point bleu indique que c'est actif
    Afficher la zone cadrée Affiche ou masque le cadre de la zone cadrée ; un point bleu indique que c'est actif
    Isoler temporairement Masque ou isole des éléments ou des catégories dans cette vue jusqu'à ce que vous la réinitialisiez ; encadré lorsqu'il est actif

    Dans une vue 3D, la barre comporte le Style graphique (Filaire, Lignes, Ombré, Ombré avec arêtes, Couleurs pleines) et Isoler temporairement. Une feuille n'a pas de barre de contrôle d'affichage : ses vues ont leur propre échelle.

    Barre de navigation

    Sur le bord droit de la vue active (le bord gauche en arabe), trois boutons : Zoom tout (comme Home), Zoom avant et Zoom arrière.

    En dessous, Options de zoom ouvre le menu du zoom : Zoom sur une région (faites glisser un rectangle sur la vue ; Esc abandonne), Zoom arrière (2x), Zoom adapté à la fenêtre, Tout adapter à la fenêtre (chaque fenêtre ouverte), Zoom taille de la feuille (la vue à sa taille d'impression), et Panoramique/zoom précédent et Panoramique/zoom suivant, qui reculent et avancent parmi les cadrages de cette fenêtre. Tapés : ZR, ZO, ZF, ZA, ZS, ZP. La roue de navigation n'est pas disponible.

    Se déplacer dans les vues

    Dans les plans, coupes, élévations et feuilles
    Molette de la souris Zoome en avant et en arrière au niveau du curseur
    Glisser avec le bouton central Panoramique
    Glisser avec le bouton gauche Une fenêtre de sélection, ou déplace les éléments sélectionnés (Sélection et modification)
    Home Ajuste toute la vue à la fenêtre
    Dans les vues 3D
    Glisser avec le bouton droit, ou Shift + bouton central Orbite autour du modèle
    Glisser avec le bouton central Panoramique
    Glisser avec le bouton gauche Une fenêtre de sélection, ou déplace les éléments sélectionnés
    Molette de la souris Zoome en avant et en arrière
    Home Ajuste tout le modèle à la fenêtre

    Un petit trièdre dans le coin inférieur de la vue 3D indique les directions des axes : X en rouge, Y en vert, Z en bleu. Une vue 3D enregistrée mémorise l'endroit où vous l'avez laissée.

    En 3D, la molette zoome en gardant fixe le point du modèle sous le curseur, et l'orbite tourne autour du centre de la sélection, ou autour du point visé par la vue quand rien n'est sélectionné.

    Le Cube d'orientation, dans le coin supérieur de la vue 3D, tourne avec le modèle. Ses arêtes et ses sommets sont chanfreinés et chaque partie est une cible à part : les six faces (DESSUS, DESSOUS, AVANT, ARRIÈRE, DROITE, GAUCHE, leurs noms écrits dessus en perspective et tournant avec elles) regardent ce côté de face ; les douze bandes des arêtes regardent depuis entre deux côtés ; les huit triangles des sommets depuis entre trois (une vue isométrique). La partie sous le pointeur prend la couleur de mise en évidence, celle d'où la vue regarde maintenant reste mise en évidence ; un clic tourne la vue jusque-là en une brève transition. Faites glisser le cube pour orbiter.

    Sous le cube est écrite l'orientation de la vue : Avant · perspective, Dessus – Avant · perspective, Isométrique · perspective, ou Libre · perspective quand la vue ne regarde depuis aucune partie du cube.

    Quand une face est vue de face, quatre triangles autour du cube (Tourner vers le haut, Tourner vers le bas, Tourner à gauche, Tourner à droite) tournent la vue d'un quart vers la face au-delà de ce côté. Les deux flèches courbes en haut à droite, Pivoter à gauche et Pivoter à droite, tournent l'image d'un quart de tour dans le sens antihoraire ou horaire.

    Le petit bouton à la maison en bas à gauche, Vue de départ, revient à la vue de départ ; un clic droit dessus donne Définir comme vue de départ, qui fait de la vue actuelle la vue de départ (chaque vue 3D a la sienne, enregistrée avec le projet). Le petit bouton en bas à droite, Menu du cube, ou un clic droit sur le cube, ouvre le menu : Orthogonale / Perspective (pour l'instant la vue est seulement en perspective : Orthogonale est grisé, « Pas encore disponible ») ; Définir comme vue de départ ; Zoom adapté à la fenêtre, qui adapte le modèle à la fenêtre ; Options…, qui ouvre la page Cube d'orientation des Options. De droite à gauche (arabe) le cube se place en haut à gauche et les deux petits boutons changent de côté ; les flèches restent là où elles pointent.

    Le menu contextuel d'une vue

    Cliquez avec le bouton droit dans une vue lorsqu'aucun outil n'est actif. Si le curseur se trouve sur un élément non sélectionné, l'élément est d'abord sélectionné. Le menu comporte :

    • Annuler : efface la sélection ;
    • Sélectionner toutes les occurrences ▸ Visibles dans la vue ou ▸ Dans tout le projet : les éléments du même type ; Sélection précédente : la sélection faite auparavant ;
    • Masquer dans la vue ▸ Éléments ou ▸ Catégorie : masque les éléments sélectionnés, ou leurs catégories entières, dans cette vue ;
    • Graphisme personnalisé ▸ Par catégorie… : ouvre Visibilité et graphisme sur les catégories de la sélection ;
    • Visibilité et graphisme….

    Lorsqu'un outil est actif, un clic droit ouvre plutôt le menu de l'outil, et l'étape en cours reste : Annuler (ce que fait Esc, qui annule toujours l'étape), Répéter [commande], Remplacements d'accrochage ▸ (l'accrochage du point suivant, comme les touches SE, SM, SN, SI et SO ; seulement dans les plans et les vues 2D libres), Zoom sur une région, Zoom arrière (2x), Zoom adapté à la fenêtre, Panoramique/zoom précédent, Panoramique/zoom suivant et Propriétés. C'est le même dans les plans, les coupes, les élévations, les vues 3D et sur les feuilles, dans les deux styles d'interface. Dans une esquisse, les remplacements valent dans toutes les vues, avec aussi Centre et Perpendiculaire. Menu ouvert, Esc ou un clic dans la vue ne font que le fermer.

    En haut du menu, Répéter [commande] relance le dernier outil utilisé ; Enter fait de même quand aucun outil n'est actif et que la ligne de commande est vide. Le menu est le même dans les plans, les coupes et les vues 3D.

    Ligne de commande

    Sous la zone de dessin, la ligne de commande affiche le journal de ce qui a été fait, le plus récent en bas : les commandes exécutées, en gris après un >, leurs résultats, et les erreurs en rouge. Sur sa dernière ligne, l'invite indique ce qu'attend l'outil actif, par exemple WALL next point [Esc to finish]:, ou Command: lorsqu'aucun outil n'est actif.

    Vous n'avez pas besoin de cliquer dessus : tout ce que vous tapez lorsqu'aucun champ n'est en cours de modification va dans la ligne de commande. Enter exécute la ligne ; Up et Down rappellent les lignes tapées auparavant. Le chapitre sur la ligne de commande décrit les commandes.

    Barre d'état

    Dans le style Classique, ces informations se trouvent à l'extrémité droite de la barre des options.

    À gauche, la barre d'état affiche :

    • lorsqu'un outil est actif, ce qu'attend l'outil (la même invite que dans la ligne de commande) ;
    • sans outil, la catégorie et le type de l'élément sous le curseur, comme Murs : Mur extérieur - Brique alvéolaire 300 + ITE ;
    • pendant un glisser, la longueur du déplacement, comme Déplacer : 1500 ;
    • sinon, un aide-mémoire de la souris : Clic : sélectionner · Ctrl : ajouter · Maj : retirer · Molette : zoom · Milieu : panoramique dans les plans, Clic : sélectionner · Bouton droit : orbite · Bouton central : panoramique · Molette : zoom en 3D.

    À droite, le nombre d'éléments sélectionnés et un entonnoir : cliquez sur le nombre pour ouvrir Filtre. Puis Sélectionner et faire glisser, qui permet de faire glisser des éléments sans les sélectionner d'abord ; dans un plan, également les coordonnées du curseur en mètres.

    La sélection, en bref

    Le chapitre sur la sélection et la modification décrit la sélection en détail. L'essentiel :

    • cliquez sur un élément pour le sélectionner ; cliquez sur un point vide pour effacer la sélection ;
    • Ctrl + clic ajoute un élément à la sélection, Shift + clic l'en retire ; Tab met en évidence l'élément suivant sous le curseur, ou une chaîne de murs joints ;
    • faites glisser de gauche à droite pour sélectionner ce qui se trouve entièrement à l'intérieur du rectangle, de droite à gauche pour sélectionner ce qu'il touche ;
    • faites glisser un élément sélectionné pour le déplacer ;
    • Ctrl+A sélectionne les éléments du niveau du plan ouvert, ou de tout le modèle dans une vue 3D ; Del supprime la sélection ; Esc l'efface.

    Mode tactile

    Le Mode tactile dispose l'interface pour les écrans tactiles et les stylets : téléphones, tablettes et moniteurs tactiles. Il exécute les mêmes commandes que les deux autres styles, avec les mêmes noms ; seule la disposition change, et chaque commande est assez grande pour un doigt.

    L'activer

    Menu de l'application ▸ Options ▸ Interface utilisateur ▸ Mode tactile a trois valeurs :

    Valeur Effet
    Automatique Actif là où l'appareil est conçu pour le toucher : dans un navigateur avec le doigt comme pointeur ou une fenêtre d'au plus 900 pixels de large, et sous Android. Sur le bureau il reste éteint
    Toujours Toujours actif, sur le bureau aussi (un moniteur tactile, une tablette PC)
    Jamais Jamais actif

    BIMopen retient le choix avec les autres préférences. Menu ▸ Quitter le mode tactile ramène l'autre interface jusqu'au prochain démarrage.

    Téléphone, paysage et tablette

    La disposition suit la place qu'a la fenêtre :

    • étroite et haute (un téléphone) : une barre supérieure compacte avec le menu, le projet et la vue (un toucher ouvre les vues), Annuler, Rétablir, Commande ou recherche et Stylet ; le dessin occupe toute la largeur ; cinq grands boutons en bas, Vues, Familles, Outils (Modifier quand quelque chose est sélectionné), Propriétés et Commandes, chacun ouvrant un panneau depuis le bas. Faites glisser la poignée du panneau vers le haut pour l'agrandir, vers le bas pour le réduire ou le fermer ; un toucher à côté le ferme ;
    • basse et large (un téléphone à l'horizontale) : une barre à gauche avec les catégories Modéliser, Structure, MEP, Annotations, Vues et Projet, plus les vues et les propriétés ; les panneaux s'ouvrent à droite ;
    • large (une tablette, un moniteur tactile) : la barre ouvre une palette d'outils pour chaque catégorie, les propriétés restent à droite, la barre des vues et familles en bas et le champ Commande ou recherche dans la barre supérieure.

    Les outils sont de grandes tuiles avec une icône et un nom. Un outil encore à venir est grisé, Pas encore disponible ; un outil qui ne fonctionne pas dans la vue 3D (Niveau, Quadrillage, Plan de référence, les annotations) y est grisé, Non disponible dans la vue 3D. Un toucher sur une tuile grisée dit pourquoi.

    Pendant qu'un outil travaille, une bande verte sous la barre supérieure montre ses options et Terminer, qui l'arrête (ou achève une esquisse). Pendant que vous dessinez un mur, Longueur… ouvre la ligne de commande : tapez la longueur du mur suivant et, si besoin, son angle, comme 4,5 ou 4,5 90.

    Un toucher sélectionne, et les murs sélectionnés montrent de grandes poignées à leurs extrémités. Sur le dessin une barre flottante propose Déplacer, Copier, Faire pivoter, Symétrie, Propriétés et Supprimer ; un appui long ouvre le menu contextuel. En bas à gauche le bouton de la vue montre l'échelle et le style graphique et ouvre Échelle, Détail, Style graphique, Soleil et ombres, Cadrage et Isoler temporairement ; en bas à droite Zoom adapté à la fenêtre.

    Gestes et stylet

    Geste Ce qu'il fait
    toucher sélectionne, ou place le point de l'outil actif
    glisser d'un doigt comme à la souris : une fenêtre de sélection, une poignée, un élément
    appui long le menu contextuel
    deux doigts déplacent la vue ; écartez ou rapprochez-les pour zoomer ; dans la vue 3D tournez-les pour faire pivoter le modèle
    double toucher adapte la vue à la fenêtre

    Stylet dans la barre supérieure est pour un stylet : le stylet dessine et sélectionne, les doigts ne font que déplacer la vue (un doigt déplace, deux doigts déplacent, zooment et tournent). Une palette du stylet sur le côté du dessin a Sélectionner, Mur, Porte, Fenêtre, Ligne de détail, Alignée, Texte et Autres outils…. Dans un navigateur c'est le navigateur qui distingue le stylet du doigt ; dans l'application de bureau un toucher qui indique une pression est pris pour un stylet.
