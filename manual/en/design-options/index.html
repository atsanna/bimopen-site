    Design options

    Design options keep several solutions for one part of the project in the same file: two entrances, three roofs, different room layouts. Everything common to all solutions is the main version; each problem gets an option set with its options. One option of each set is the primary: the views show the main version with the primaries, until a view is dedicated to another option or an option is being edited. When the client has chosen, Accept primary puts the chosen option into the main version and removes the others.

    Option sets and options

    Project ▸ Options ▸ Design options (BIMopen style: Project ▸ Design options…) opens the Design options dialog. On the left, every set with its options; (primary) follows the primary's name; under the list, Editing: says what is being edited.

    Group Button What it does
    Modify Edit option the selected option becomes the active one
    Finish editing back to the main version
    Option New a secondary option of the selected set, «Option N»
    Duplicate a secondary option «Copy of …» with copies of the option's elements
    Make primary the option becomes the primary, the old primary a secondary
    Delete the option with its elements (not the primary, not while editing)
    Rename a new name for the option
    Option set New «Option set N» with «Option 1 (primary)»
    Delete after a confirmation, the set with all its options and their elements
    Rename a new name for the set
    Accept primary the primary joins the main version, the set goes

    Names are unique within their list and cannot contain «:».

    Editing an option

    To add elements to an option, make it the active option in one of these ways:

    • Edit option in the dialog (or a double click on the option);
    • the drop-down Main version of Project ▸ Options, of the status bar and, in the BIMopen style, the chip Option: … in the top bar beside the phase chip;
    • Select to edit, then a click on an element of the option.

    While an option is active, every model element you make goes into it, and everything outside it is drawn in halftone in plans, sections, elevations and 3D views and cannot be selected while Active only is on in the status bar. Levels, grids, views, dimensions, tags, text and detail lines always belong to the main version or to their view; a section, elevation or callout made while editing is visible only in that option (see Dedicated views). Finish editing, or Main version in a drop-down, ends the editing. Switching the active option is not an undo step, and a project always opens in the main version.

    Doors, windows and wall openings stay in the option of their wall, a stair's railings in its stair's, a strip footing in its wall's: a door cannot be placed in a main-version wall while an option is edited. Move the wall into the option first.

    In the status bar, with the main version edited, Exclude options keeps the elements of the options from being selected; untick it to select them (to dimension to them, say). Hovering an element of an option shows «(Set : Option) : Category : Type», and its properties show Design option under Identification.

    The status bar's design option controls are always there, greyed in a project with no options; Views ▸ Windows ▸ Panels ▸ Status bar - Design options hides or shows them; in the BIMopen style they are also in the menu of the chip Option: ….

    Moving elements into options

    Select main-version elements and click Project ▸ Options ▸ Add to set. In Add to option set choose the set under Add selection to and tick the options that get the elements: the first ticked option takes the elements, the others get copies, and they leave the main version. What a selected wall hosts goes with it; a door alone cannot go without its wall.

    Elements of one option move to another with Cut (Ctrl+X) in the first, then, with the other option active, Paste ▸ Paste in the same place.

    Groups and arrays are made of elements of the active option only (or of the main version only).

    Dedicated views

    Visibility and graphics has a Design options tab in projects with options: one row per set, with the option the view shows. Automatic shows the primary, or the active option when it is of that set; choosing an option dedicates the view to it. Duplicate a view (with details too), dedicate it, and put it on a sheet beside the other to compare the solutions.

    A schedule's Visibility and graphics (VV in the schedule) has only this tab: its rows are the main version and the options it shows.

    The view property Visible in option (Graphics) binds a view to one option: its mark (the section line, the elevation symbol, the callout) shows only in views showing that option, and the view goes when the option is deleted. All shows it everywhere.

    Rooms, joins and outputs

    • A main-version room is bounded by the main version and every primary; a room of an option by its option, the main version and the primaries of the other sets. Volumes take floors, roofs and ceilings by the same rule. Areas and area schemes are never in an option.
    • Main-version walls join the primaries' walls as they join each other, but never a secondary option's walls: move such a wall into the option to join it.
    • Plans, sections, elevations, 3D views, sheets, PDF and DWG/DXF show each view's options; IFC holds the main version and the primaries.

    Make primary, delete, accept

    Make primary carries over what refers to the old primary from the main version: the walls attached to its roofs or floors, and the dimensions and tags of the views showing it by Automatic, move to the matching elements of the new primary (copies of the same element, else the nearest of the same kind). When some find no match, a window lists them: Delete and make primary deletes those dimensions and tags and detaches those walls.

    Delete an option, when views are dedicated to it, lists them in Delete dedicated views, ticked: the unticked ones stay and show Automatic again; those Visible in option of it are ticked and cannot be unticked. The primary cannot be deleted: make another option primary, or delete the set.

    Accept primary says which option joins the main version and which go, with how many elements, and lists the views dedicated to them. Accept does it in one step: Undo (Ctrl+Z) brings the set back.
